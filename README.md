# Dikya — unified Design QA

Single-page React prototype. Vite + React 18 + Tailwind v4 + lucide-react.

## Run locally

```bash
npm install
npm run dev          # http://localhost:5173
```

## Build

```bash
npm run build        # → dist/
npm run preview      # serve the build locally
```

## Deploy to Vercel

Push to GitHub, then import the repo at vercel.com/new.
Vercel auto-detects Vite: build `npm run build`, output `dist`.
